Sistem Komputer

Komponen dan Cara Kerja

Sistem Komputer adalah kumpulan perangkat (hardware, software, brainware) yang saling berinteraksi untuk mengolah data menjadi informasi berharga.

Sudut Pandang Islam

"Bacalah dengan (menyebut) nama Tuhanmu..." (QS. Al-'Alaq: 1)

Gunakanlah teknologi ciptaan manusia atas izin Allah ini untuk meraih pahala dan kebaikan umat.

4 Hardware Utama

1. Input (Masukan)

Memasukkan data.
Contoh: Keyboard, Mouse, Scanner.

2. Process (Proses)

Otak komputer pengolah data.
Contoh: CPU (Processor), RAM.

3. Storage (Penyimpanan)

Menyimpan data/program.
Contoh: Harddisk, SSD, Flashdisk.

4. Output (Keluaran)

Menampilkan hasil visual/cetak/suara.
Contoh: Monitor, Printer, Speaker.

Alur Kerja

INPUT PROCESS OUTPUT

Software & Brainware

Perangkat Lunak (Software)

Program yang berisi instruksi digital untuk menjalankan hardware.
Contoh: Windows, Android, Chrome.

Pengguna (Brainware)

Manusia yang mengoperasikan dan mengendalikan komputer. Tanpa manusia, sistem tidak akan berfungsi.
